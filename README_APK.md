# ГРАВИ-РАН 3D — как собрать APK в Android Studio

Игра написана на WebGL (это OpenGL ES в браузере) и работает как есть на любом
телефоне/ПК. Чтобы получить нативный **APK-файл**, оберни её через **Capacitor** —
весь 3D-движок, звук и управление будут работать нативно в WebView с аппаратным
ускорением OpenGL ES.

## Быстрый вариант (5 минут)

```bash
# 1. Собери веб-версию
npm run build            # появится папка dist/

# 2. Установи Capacitor
npm install @capacitor/core @capacitor/cli @capacitor/android

# 3. Инициализируй проект приложения
npx cap init "ГРАВИ-РАН 3D" com.you.graviran --web-dir=dist

# 4. Добавь Android-платформу
npx cap add android

# 5. Скопируй сборку в android-проект
npx cap sync
```

## Дальше в Android Studio

1. **File → Open** → выбери появившуюся папку `android/`.
2. Дождись синхронизации Gradle (используется твой установленный SDK).
3. **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
4. Готовый APK будет в `android/app/build/outputs/apk/debug/app-debug.apk`
   (или запусти сразу на телефоне через кнопку **Run**).

## После изменения кода игры

```bash
npm run build && npx cap sync
```
и снова Build APK в Android Studio.

## Что уже настроено в игре

- `manifest.webmanifest` + иконка 512px (PWA: можно «Добавить на главный экран» без APK).
- Полноэкранный режим, запрет зума, touch-управление (свайпы/тапы), автопауза при сворачивании.
- Локальное сохранение рекорда.

## Управление

| Действие | Телефон | ПК |
|---|---|---|
| Смена дорожки | свайп ← → | стрелки / A, D |
| Сальто на потолок / прыжок | тап | Пробел / W / ↑ |
| Быстро спуститься с потолка | свайп вниз | S / ↓ |
| Пауза | кнопка на экране | P / Esc |
